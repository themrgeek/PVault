PVault API Documentation

Authentication Endpoints

Base URL: http://localhost:3000/api/v1

POST /users
Register a new user account.

Request body

{
  "email": "user@example.com",
  "password": "Password123!"
}

Success response (201)

{
  "id": "64d5f22c1b2e4d9a8e1f3c6d",
  "email": "user@example.com",
  "createdAt": "2026-10-02T12:00:00.000Z"
}
POST /sessions
Log in with an email and password to get a JWT token.

Request body

{
  "email": "user@example.com",
  "password": "Password123!"
}

Success response (200)

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "tokenType": "Bearer",
  "expiresIn": "1h"
}
Use the returned token in the Authorization header as: Bearer <token>
DELETE /sessions/current
Log out the current authenticated user.

Headers

Authorization: Bearer <token>

Success response (204)

No content
GET /users/me
Get the authenticated user's profile details.

Headers

Authorization: Bearer <token>

Success response (200)

{
  "id": "64d5f22c1b2e4d9a8e1f3c6d",
  "email": "user@example.com",
  "createdAt": "2026-10-02T12:00:00.000Z"
}
GET /auth-logs
View all authentication logs belonging to the authenticated user, newest first.

Headers

Authorization: Bearer <token>

Success response (200)

{
  "logs": [
    {
      "id": "74d5f22c1b2e4d9a8e1f3c6d",
      "timestamp": "2026-10-04T09:30:00.000Z",
      "eventType": "login_succeeded",
      "details": { "ipAddress": "203.0.113.10" }
    }
  ]
}
DELETE /auth-logs
Delete authentication logs belonging to the authenticated user.

Headers

Authorization: Bearer <token>

Success response (200)

{
  "deletedCount": 12
}
GET /auth-logs/export
Download the authenticated user's authentication logs as newline-delimited JSON in a text file.

Headers

Authorization: Bearer <token>

Success response (200)

Content-Type: text/plain; charset=utf-8
Content-Disposition: attachment; filename="auth-logs.txt"

{"timestamp":"2026-10-04T09:30:00.000Z","userId":"64d5f22c1b2e4d9a8e1f3c6d","eventType":"login_succeeded","details":{"ipAddress":"203.0.113.10"}}
GET /auth-logs/backup
Download a JSON backup of the authenticated user's account metadata and authentication logs. Password hashes are not included.

Headers

Authorization: Bearer <token>

Success response (200)

Content-Disposition: attachment; filename="auth-backup.json"
Content-Type: application/json

{
  "exportedAt": "2026-10-04T09:30:00.000Z",
  "user": {
    "id": "64d5f22c1b2e4d9a8e1f3c6d",
    "email": "user@example.com",
    "createdAt": "2026-10-02T12:00:00.000Z",
    "updatedAt": "2026-10-03T12:00:00.000Z"
  },
  "authLogs": [
    {
      "id": "74d5f22c1b2e4d9a8e1f3c6d",
      "timestamp": "2026-10-04T09:30:00.000Z",
      "userId": "64d5f22c1b2e4d9a8e1f3c6d",
      "eventType": "login_succeeded",
      "details": { "ipAddress": "203.0.113.10" }
    }
  ]
}
